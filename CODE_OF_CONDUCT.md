# Code of Conduct

We are committed to a respectful, harassment-free project for everyone.

Be constructive, assume good intent while evaluating technical claims against evidence, respect privacy, and avoid sharing target-repository secrets or private communications. Harassment, discrimination, threats, doxxing, and sustained disruption are not acceptable.

Maintainers may edit, remove, or reject contributions and community interactions that violate these expectations. Report conduct concerns privately to the repository owner. Reports will be handled as confidentially as practical.

This project uses the Contributor Covenant as its interpretive baseline: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
