4. Run a named host against an installed candidate, then repeat checks against the actual public download. Keep stdout, exit codes and digest evidence tied to each installation.

## Component Design

GoReleaser owns the six CGO-free archives, checksums and per-archive SPDX files. The tag workflow verifies notes and skill contents on the draft, attests the subjects and publishes once. A later read-only job can run the Windows public installer. A failed post-publication check leaves the immutable release available for diagnosis.

The installer owns acquisition and installation. The agent reads the matching skill, runs inspection and proposes canonical inputs. SSB validates and projects those files. Resume assesses the proposal without writing. Capture the git index and file identities before and after each recovery step. Record the developer's actual review separately from the host's recommendations.

## Failure And Recovery Rules

- Invalid downloads, invalid checksums, unsafe destinations and interrupted installs must preserve preexisting binary and skill contents. Capture exit status and path bytes, correct the input and retry into an isolated directory.
- Stop generation after a retained partial proposal. Check reuse flags and raw-byte digests, correct only the affected material, validate, dry-run, render and replay. Preserve manual instructions, unrelated files, installed skills and staged state.
- A failed draft gate stops publication. Diagnose the failing step and review any repair against the same accepted contract. Published assets and historical tags are immutable. A verified defect in public bytes requires a separately reviewed corrective release.

## Definition Of Done

1. The reviewed, merged source passes the native suite, configuration checks, six-archive contract and cross-platform CI. The changelog's date matches the signed tag's date.
2. A named host uses the matching installed skill and binary to recover a proposal at a named fixture commit. Retained evidence identifies the files preserved, the correction, the review basis and the Proposed ADR.
3. The signed tag points to the verified merge. Its public immutable release has the curated body, all six archives, matching checksum and SPDX subjects, and verified provenance and SBOM attestations.
4. Independent public installations run the documented commands and recovery checks. Each receipt identifies the versions, commit, platform, fixture, result and limits.

## Assumptions And Defaults

Choose the next free feature-bearing minor version. Keep the previous public evidence at its original paths. Keep large transcripts in disposable storage and retain only the compact observations needed for verification. Record candidate, signed, published and installed identities separately.
